# Emotion Detection System 🎭

An NLP-based Emotion Detection System built using:

- TF-IDF Vectorization
- Logistic Regression
- Multinomial Naive Bayes
- Streamlit
- Plotly

## Features

- Detect emotions from text
- Multiple ML models
- Probability visualization
- Modern Streamlit UI

## Tech Stack

- Python
- Scikit-Learn
- NLTK
- Streamlit
- Plotly
